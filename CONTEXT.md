# Fire Conference

Sistema de inscrições para a Fire Conference, um evento único da igreja com lotes de preço.

## Language

**Inscrição**:
O registro de uma pessoa participando do evento, vinculado a um lote e com um status de pagamento.
_Avoid_: Registro, cadastro

**Lote**:
Uma faixa de preço e vagas do evento. Tem limite próprio de vagas; ao esgotar, fecha sem lista de espera.
_Avoid_: Turma, categoria

**Comprovante**:
Arquivo (imagem ou PDF) anexado pelo inscrito como evidência do pagamento via Pix, revisado manualmente por um aprovador de pagamento.
_Avoid_: Recibo, prova de pagamento

**Pix Copia e Cola**:
Código de pagamento Pix gerado para uma inscrição específica, com o valor exato do lote já embutido, que o inscrito cola no app do banco para pagar.
_Avoid_: QR code (o copia-e-cola é o dado subjacente; o QR é apenas uma representação visual dele)

**Aprovador de pagamento**:
Papel de admin responsável por revisar comprovantes e confirmar ou rejeitar inscrições.
_Avoid_: Admin financeiro

**Time de check-in**:
Papel de admin responsável por validar a entrada dos inscritos no dia do evento.
_Avoid_: Recepção

**Responsável**:
Contato de um inscrito menor de idade (nome e celular), coletado na inscrição para que a organização entre em contato quando necessário.
_Avoid_: Guardião, tutor

**Ingresso**:
Documento gerado para uma inscrição confirmada, contendo um QR code, usado para validar a entrada no dia do evento.
_Avoid_: Bilhete, ticket

**Cupom**:
Código aplicado numa inscrição para reduzir o valor do lote (ex: valor fixo para quem vai servir no evento).
_Avoid_: Voucher, desconto
