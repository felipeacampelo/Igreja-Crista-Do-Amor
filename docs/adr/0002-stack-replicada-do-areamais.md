# Stack replicada do AreaMais

A Fire Conference replica a stack do AreaMais — Django REST Framework + React/Vite/TypeScript como dois serviços separados, Postgres, deploy no Railway — em vez de uma stack mais enxuta (ex.: Next.js full-stack + Supabase) que seria proporcional ao escopo menor deste projeto. Decidido para manter consistência de ferramentas e padrões entre os projetos da igreja, mesmo custando alguma sobrecarga operacional extra (dois serviços deployados em vez de um).
